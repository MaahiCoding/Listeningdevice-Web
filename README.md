# ListenIn — Marketing Website

Landing page for **ListenIn**, an AI-powered listening device app that captures, transcribes, and surfaces what matters — in real time.

## What This Is

A static marketing site. No backend, no database, no framework. Just plain HTML, CSS, and a little JavaScript served via Vercel.

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Homepage — hero, features, stats, waitlist signup |
| `style.css` | All styles |

## Features Highlighted

- Real-time transcription (< 300ms latency)
- AI smart highlights — action items, decisions, key moments
- On-device privacy — audio never leaves your device
- 40+ languages with auto-detection
- Integrations with Notion, Slack, Calendar
- 28-hour battery life

## Tech Stack

- Plain HTML5 / CSS3 / Vanilla JS
- No frameworks, no build step
- Deployed on Vercel

## Local Development

1. Clone the repo
   ```bash
   git clone git@github.com:MaahiCoding/Listeningdevice-Web.git
   cd Listeningdevice-Web
   ```
2. Open `index.html` in your browser, or use the **Live Server** VSCode extension for live reload.

## Deployment

Pushed to `main` → Vercel auto-deploys in ~30 seconds.
